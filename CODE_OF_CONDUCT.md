# Code of Conduct

THERMAL is a technical project for performance and systems engineers. Contributors are
expected to:

- Keep discussion focused on evidence: benchmarks, reproduction steps, measured data.
- Disagree about engineering approaches without personal attacks.
- Assume good faith from other contributors, and correct mistakes (including your own,
  including fabricated or mistaken benchmark claims) openly rather than defensively.

Harassment, discriminatory language, or personal attacks are not tolerated. Reports can
be made by opening a GitHub issue tagged `conduct` or, if sensitive, by contacting the
repository maintainer directly.

This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
